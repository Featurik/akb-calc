# АКБ калькулятор

Файлы обновлений программы «АКБ калькулятор» (Windows): установщик, описание версии `akb_calc_update.json` и его подпись `akb_calc_update.json.sig`.

Программа проверяет обновления сама (раз в 6 часов и при запуске) и ставит только версию с верной подписью ECDSA P-256 и совпадающей контрольной суммой SHA-256. Исходников здесь нет.

Скачать вручную: раздел **Releases** → последний выпуск → `AKB_Calc_Setup_<версия>.exe`.
